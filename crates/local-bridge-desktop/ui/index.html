本机环境

Agent 可用性

启动时自动检查，复用原有登录与已保存的参数。修复登录或配置后可重新检查。

Agent 默认设置

只为未明确指定参数的新任务提供默认值；不会改变网站授权。

自动选择优先顺序

上下移动；不会绕过 Origin 授权或 Agent 能力检查。

安全与授权

网站的 Agent 使用权限仍按完整 Origin 单独授权；桌面首版不提供任意网站批量授权。

local-bridge web-v2 grant-agent https://your-app.example codex

账号登录、模型 API、额度与费用由各 Agent 或企业服务负责，Local Bridge 不保存这些凭据。

复用已有平台

自动发现已安装的工具；安装与修改其他软件配置只在主动点击后执行。
